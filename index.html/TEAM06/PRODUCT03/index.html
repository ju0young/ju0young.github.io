PROBLEM

잘못된 AI 안내 정보가 실제 경험과 구매에 영향을 미친다.

  1. 01AI의 대기시간 예측 오류가 이용객의 방문 여부와 이동 경로 결정에 직접적인 영향을 미친다.
  2. 02실제 대기시간과 안내 정보의 차이로 인해 불필요한 시간 낭비와 이동 불편이 발생할 수 있다.
  3. 03잘못된 AI 정보가 이용객의 시장 탐색 경험과 서비스 신뢰도에 부정적인 영향을 미친다.
  4. 04지나면서도 매장 방문 여부를 고민하고 이동을 결정하는 핵심 단계에 부담감이 커진다.
03

KEY FEATURES

핵심 기능  AI 기반 빅데이터를 활용한 시장 탐색 지원

01 흥정하고 가치 있는 상품 발견

시장 곳곳에 설치된 센서가 흥정 소리를 감지하고 분석하여 현재 거래가 이루어지는 장소와 관련 정보를 파악한다.

02 거래가 활발한 매장 확인

대형 디스플레이에서 현재 거래가 활발한 구역과 인기 상품을 확인할 수 있다.

03 시간과 비용을 아끼는 효율적인 쇼핑

구매별 거래 활동 데이터를 바탕으로 상품을 정리하고 불필요한 시간 낭비를 줄여 효율적인 쇼핑을 지원한다.
